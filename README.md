# KochiCraft — 高知県 観光地 3D英語教材

ボクセル（キューブ）で再現した高知県の観光地を見て回り、**英語で観光案内を学ぶ**小学生向けの教育アプリです。
**外部API・ネット接続・アカウント不要**（完全オフライン、ブラウザ標準機能のみ）。見た目は特定の商用ゲームに依存しないオリジナルデザイン（色だけのキューブ・テクスチャ不使用）で、著作権に配慮しています。

> 🧭 開発を引き継ぐ場合は、まず **`HANDOVER.md`**（全体像）→ **`CLAUDE.md`**（作業ルール）→ **`TODO.md`**（やること）の順に読んでください。

---

## これは何か（重要）
- **自由に歩き回るオープンワールドゲームではありません。**
- **「観光地を選んで、その場所だけの小さな3D空間を見て学ぶ」教材**です。
- 起動 → **高知県 観光地一覧（ハブ）** → 観光地を選ぶ → その観光地の**コンパクトな3Dワールド**へ。
- **UI も解説もすべて英語**（小学5年生レベル）。
- **マウスは使いません**（キーボード＋タッチのみ）。

## 必要環境
- Node.js 18 以上（推奨 20+）

## セットアップ
```bash
npm install      # 初回のみ
npm run dev      # 開発サーバ（http://localhost:5173 が自動で開く）
```

## ビルド（配布用・オフライン動作）
```bash
npm run build    # 型チェック(tsc --noEmit) + 本番ビルド(vite) → dist/
npm run preview  # ビルド結果の確認
```
`dist/` は相対パスで動くため、フォルダごとコピーすればネット無しで開けます。

## 操作方法（マウス不使用）
キーは**英単語の頭文字**にそろえています（**J**ump / **L**ook / **B**uild / **D**one / **P**ut / **T**ake / **W**alk / **H**ome / **E**nglish / **C**hange Character / **V**iew / **I**nfo / **N**ext / **K**eys）。

**Walk（歩く・既定）**
- 移動：**矢印キー ↑ ↓ ← →** または画面**右下**の方向ボタン **▲ ◀ ▼ ▶**（JUMPは左下）
- 振り向く：**Shift ＋ ← →**
- 見上げる／見下ろす：**U**（Up）/ **D**（Down）、または **Shift ＋ ↑ ↓**
- ジャンプ：**J**（Jump）または **Space** / **JUMP** ボタン
- 構造物を選ぶ：**Enter**（または **I**＝Info）／**N**（Next＝次の対象へ）／タップでも可
  - 何も見ていないときは「Look at a building, then press Enter」と出ます
- 英語を聞く：**E**（English）
- 視点はタブレットなら **画面ドラッグ** でもOK
- 画面左下に **🎮 Keys**（キー案内）が出るので、操作を覚えなくても迷いません

**Map（行ける場所の一覧）**
- **M**（Map）または「🗺️ Map」ボタンで、その観光地の**行ける場所の一覧**が開きます。
- **↑↓ で選んで Enter**（タップでも可）すると、**その場所へ移動して説明パネルが開きます**。
- 場所は全12観光地で**合計81か所**。一覧は [`名所リスト.md`](名所リスト.md) にもまとめてあります（写真の準備用）。
- 写真を AI で作るときは [`画像プロンプト.md`](画像プロンプト.md) の ChatGPT 用プロンプト（81枚ぶん）をコピーして使えます。

**キャラクターと視点（Walk のとき）**
- **C**（Change Character）でキャラクターを変える：**Boy（男の子）→ Girl（女の子）→ Pet（ペット）→ Robot（ロボット）**
  - すべて四角いブロックだけで作ったオリジナルの造形です（既存ゲームのキャラクターは使っていません）。歩くと手足が振れます。
- **V**（View）で見え方を変える：
  1. **Eyes**（一人称・自分の目。キャラクターは映りません）
  2. **Back**（うしろ視点・背中を見ながら歩く）
  3. **Far**（三人称・引いて全体を見る）
  4. **Face**（正面視点・キャラクターの顔が見える）
- 選んだキャラクターと視点は**次に開いたときも覚えています**。
- ※ブロックを作る（Build）ときは、正確にねらえるよう自動で一人称になります。

**Look（空から見る・切替）**：**L**（Look）キー。**← →**で回り、**↑ ↓**で上下、**N**（Near）/ **F**（Far）で近づく・離れる。**W**（Walk）で歩きに戻る。

**Build（ブロック編集・切替）**：**B**（Build）キー。
- 下中央の**ホットバー**でブロックを選ぶ（**数字キー 1〜9・0**）。
- **P**（Put）：中央カーソルの先に置く（ボタン **🧱 Put** は押しっぱなしでまっすぐ上に積める）。
- **T**（Take）：自分が置いた物を消す（元の地形・建物は壊れない）。
- 編集は**自動でこの端末に保存**＋ **Ctrl+S** で `.kcw` 書き出し／**Ctrl+O** で読み込み。
- **D**（Done＝ボタンの表示と同じ）か **Esc** で歩行に戻る。※編集中は **D** が Done なので、見下ろすのは **Shift＋↓**。
- ※編集モードに入ると自動で少し下を向きます（足元のブロックをすぐ置けるように）。

**その他**：**H**（Home）でスタート地点に戻れる。段差は**歩くだけで自動で登る**。観光地の外（奈落）へは落ちない。

### マウスを使わずに全部できます
- **観光地を選ぶ**：矢印キーでカードを移動 → **Enter**
- **構造物を選ぶ**：**Enter**／**I**／**N**、**閉じる**：**Esc**
- 情報パネルの中（＋の付け足し・写真・音声）は **Tab** で移動 →**Enter** で押す
- 画面の**ボタンには押すキーが書いてあり**、左下の **🎮 Keys** にモードごとの一覧が出ます
- **K**（Keys）で一覧を開いたり閉じたりできます（閉じると小さなボタンだけになり、画面の邪魔になりません。開閉の状態は次回も覚えています）

**情報パネル**：対象に近づくと**英語名バナー**、タップで **You can / Special / About**（英語）。
- **🔊 Listen**：英語を再生（先生の録音があれば優先、なければ自動音声）
- **📷 Add a photo / 🎤 Add a voice**：先生が実物写真・英語音声をアップロード（保存される）
- **写真の同梱**：`public/photos/<観光地ID>/` に画像を置くと、最初から写真が出ます（桂浜7か所は設定済み）。
  取り込みは `写真を取り込む.ps1` を実行 → ファイル名を整える → `src/spots/<観光地>.ts` に `image:` を追記。

## 技術
- TypeScript（strict）＋ Three.js（ボクセル3D）＋ Vite（ビルド）
- 音声：Web Speech API ＋ 先生のアップロード音声
- 保存：localStorage（写真・音声を dataURL で）
- バックエンド・DB・認証・外部API：**なし**

## ディレクトリ（概要）
```
src/
  core/    エンジン・カメラ(orbit/walk)・ワールド管理
  world/   ボクセル（チャンク/グリーディメッシュ/ブロック定義）
  player/  歩行の物理・衝突
  spots/   観光地データ（SpotDefinition / Build / katsurahama / SpotRegistry）★中心
  features/language  英語音声(SpeechService)
  data/    写真・音声の保存(PhotoStore)
  ui/      ハブ(HubScreen)・情報パネル(InfoPanel)・スタイル
  types/   共通型 / config/ 定数
```
> ⚠️ `editor/`・`features/quiz`・`features/teacher`・旧 `tourism`・旧 `data(save)`・旧 `ui(HUD等)`・`Clock`・`InputManager`・`PlayerController`・`TerrainGenerator`・`EventBus` は**過去のサンドボックス版の名残で現在は未使用（parked）**です（詳細は `HANDOVER.md` §3）。

## 観光地の追加（開発者向け・最短）
1. 実物を調べる → `src/spots/<id>.ts` に `SpotDefinition` を作る（`build()`＋`objects[]`＋`spawn`＋**`field`**、英語は小5、色だけのボクセル）。
2. `src/spots/SpotRegistry.ts` に `import` して `SPOTS` 配列へ追加（`available:true`）。
3. `npm run build` → `npm run dev` で確認。`katsurahama.ts` をお手本に。詳しくは `HANDOVER.md` §13。
